# Investigating Gender Bias in LLMs via Personal Narrative Generation

This repository accompanies the MSc thesis *A Tale as Old as Time: Gender Bias in LLM Narrative Generation*, co-supervised by ETH Zurich and the University of Zurich.

You can find the original thesis paper in the root folder.

The dataset of synthetic personal narratives is available [here](https://huggingface.co/datasets/kontimoleon/gender-bias-in-personal-narratives).
